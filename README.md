# 读痕·让阅读留痕（阅读统计 · 为「墨本阅读」设计 v2.7）

**只统计墨本阅读（Legado）的阅读数据，完全不需要 root，任何 Android 手机都能装。**

- App 名称：`读痕 · 阅读统计`（与旧版一致）
- 包名：`com.momocat.a5pro.readstats`（与旧版一致，覆盖安装即可）
- 版本：`v2.7 / versionCode 11`
- 适用：`minSdk 21`，实测海信 A5 Pro（Android 10）；`targetSdk 28`
- APK：`A5Pro-ReadStats-Legado-v2.7.apk`（约 49 KB）
- 图标：书本线条图标（白色圆角底 + 黑色翻开的书 + 灰色页纹），随 APK 内置 5 档密度（48–192 px）

> 旧的三源版（微信读书云端 + Reeden）已按你的要求停止，不再维护，见 `../readstats/`。
> 本版是独立项目，不依赖旧目录里的任何东西。

## 怎么用（3 步）

1. **在墨本阅读里导出备份**
   `设置 → 备份与恢复 → 备份`，得到 `backupYYYY-MM-DD.zip`。
   放在手机任意目录都行（下载、文档、WebDAV 取回的都行），不用记路径。

2. **在读痕里点「选择备份文件」**
   会打开**系统文件管理器**，选中刚才那个 ZIP 即可。
   App 自动用系统 `ZipFile` 读取备份里的 `readRecordDetail.json`（逐日阅读时长）。

3. **看统计**
   导入一次后会记住数据（WebView localStorage），之后直接打开 App 就能看，
   不用重复导入、不用连电脑、不用 root。
   想更新：重新在墨本阅读里备份一次 → 再点「选择备份文件」选中新 ZIP。

界面里还保留了「手动填写完整路径」作为备用（个别 ROM 没有系统文件管理器时可用）。

## 为什么不需要 root

无 root 手机读不到别的 App 的私有数据库（`/data/data/...`），这是 Android 沙箱限制。
所以本版**不读私有目录**，改走系统标准通道：

```
系统文件管理器 (ACTION_OPEN_DOCUMENT / SAF)
   → content:// Uri
   → ContentResolver.openInputStream
   → 复制到 App 私有缓存
   → java.util.zip.ZipFile 取 readRecordDetail.json
   → WebView 本地统计 / Canvas 出图
```

静态核验结果：

- `classes.dex` 里**没有 `su` 命令**（旧壳的 `su -c` 已改成 `sh -c`，且界面根本不调用它）
- 界面 HTML **不调用任何 shell 通道**，只用 `FS.*` 文件桥
- 全程不联网、不上传、不请求 Magisk / LSPosed / 无障碍权限
- SAF 本身不需要存储权限；Manifest 里的 `READ/WRITE_EXTERNAL_STORAGE` 只给「手动路径」和「保存到相册」用，**拒绝授权也不影响主流程**

## 已知限制

- **必须手动导出一次备份**：无 root 无法自动抓取墨本阅读的私有数据库，这是取舍不是缺陷。
- 备份需含 `readRecordDetail.json`；若没有，自动回退 `readRecordSession.json`（按会话起止时间归日）或 `readRecord.json`（仅按书总时长，无逐日趋势）。
- **导出文件夹选择在重启 App 后不保留**：会回到「未选择文件夹，将保存到默认『下载』目录」的安全状态（界面有明确提示，重新选一次即可）。
- **字体列表在重启 App 后不保留**：已应用的字体不受影响（已复制到 App 私有目录，直接生效）；想**换**字体时需重新点「选择字体文件夹」。
- **系统图标缓存**：若本机之前装过 v2.3（无自定义图标）再覆盖升级，个别 ROM 的应用信息/桌面图标可能仍显示默认图标——这是系统按包名缓存的旧图，**重启手机即可刷新**（图标本身已验证正常加载）。
- 本机是已 root 的 A5 Pro，验证在它上面完成；**未在真正无 root 的机器上实刷**，但已逐项静态核验无 root 调用、走的全是标准 SAF / ZipFile / WebView API。
- 名称与包名和旧 v1.0 相同，安装会**覆盖**旧的 root 版（数据不共用，需重新导入一次备份）。
- 「黑色」墨水屏主题下，顶部系统状态栏区域仍由系统主题控制（浅色条），App 内部已全部反白；这是系统状态栏限制，不影响使用。
